# Infernos Dragon Eyes 1.0.0

Initial release for **Minecraft 1.21.1** / **NeoForge**.

- Eyes of ender that home toward nearby wild Ice and Fire CE dragons (fire / ice / lightning)
- Craft: ender pearl + matching dragon blood
- Distinct mod id `infernos_dragon_eyes` (not a drop-in for upstream Eyes of Ice and Fire CE)

Requires Ice and Fire Community Edition 2.x.
